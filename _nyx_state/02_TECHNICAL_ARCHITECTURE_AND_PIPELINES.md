## 2. Core Data Flow & Evaluation Pipeline
1. **Ingestion (`lgsPoller.ts`, `fastTier1Poller.ts`, `bigBoxRetailPoller.ts`, `bigBoxAdapters.ts`, `bigBoxDomParsers.ts`, `bestBuyOfficialApi.ts`, `publicRestockWire.ts`, `listener.ts`, & `vampirePoller.ts`):**
   - Pollers fetch raw listings across all `90` active Shopify LGS storefronts and all `9` Big-Box 1st-Party retailers (`Target` passive RedSky `plp_search_v2` 1P `facetedValue=dq4mn`, `Walmart` `#__NEXT_DATA__` `F55CDC31AB754BB68FE0B39041159D63` 1P, `Best Buy` Official REST API + `.product-list-item` Chrome 1P, `Amazon` Webshare Proxy-First + Chrome fallback `rh=p_6:ATVPDKIKX0DER` 1P `<= MSRP*1.08`, `Pokémon Center` Direct TLS + `Queue-It` / `ROUTER_TLS_FILTER` / `Imperva` classifier, `GameStop` `data-gtmdata` object parser with `allowAboveMsrpSliderFallthrough: true`, `Barnes & Noble` Shopify Hydrogen, `Costco` passive search XHR + `ProductTile` hydration, and `Sam's Club`).
   - **Home-IP WAF Shield & Sub-Second Public Restock Wire (`wafBrowserBridge.ts` + `publicRestockWire.ts` + `listener.ts`):** After `2` consecutive Direct-IP WAF/0-node strikes on `pokemoncenter`, `target`, `walmart`, `costco`, or `samsclub`, `recordBigBoxDirectIpOutcome()` engages a `6h` `WIRE_ARMED_IP_SHIELD` (`WIRE_SHIELD` cyan tier) to protect residential IP reputation while `publicRestockWire.ts` maintains a live Bluesky Jetstream WebSocket (`wss://jetstream2.us-east.bsky.network/subscribe`) + `25s` `getAuthorFeed` backup (`@pokemonrestocks.bsky.social`, `@hoomandeals.bsky.social`) and `listener.ts` polls `r/PKMNTCGDeals` via per-request rotating Webshare proxy (`keepAlive: false`, `AbortSignal.timeout(5000)`), unshortening affiliate links to canonical 1-tap retail ATC URLs, classifying `INSTANT_BUY_RESTOCK` vs `QUEUE_INVITE_DRAWING` (`QUEUE` / `INVITE` / `DRAWING`), and deduplicating across channels (`claimBigBoxCrossChannelSignal`, `30m` TTL).
   - Full 91-store Shopify sweep also prunes disappeared variant IDs via `pruneStoreMissingOffers()`.
2. **Evaluation & Caching (`evaluator.ts`, `policies.ts`, & `src/config/configManager.ts`):**
   - `src/config/configManager.ts` (`347` lines) merges `config/catalog.json` (`131` static SKU definitions), `config/userPreferences.json` (Scott's untouchable personal sliders, `owned`/`inVault` flags, and global toggles), and `marketCache.json` (`estimatedMarketValue` / `rollingAverage` baselines) in memory.
   - `lgsPoller.ts` reads active stores and `evaluator.ts` resolves shipping rules from the single unified registry `config/stores.json` (`90` active healthy Shopify LGS stores + `9` Big-Box stores; dead 404 store `Lets Play TCG` disabled).
   - `evaluateItem()` checks `GLOBAL_JUNK_EXCLUSIONS`, matches against `WATCH_POLICIES` regexes (with `booster.*(box|display)` normalization), validates form factor via `isValidSkuForFormFactor()`, checks dynamic price floors/ceilings (`getMaxPlausiblePriceCeiling()` = `Math.max(base, estimatedMarketValue * 1.65, maxMarketBuyPrice * 1.65, msrpCeiling * 3.5)`), and runs the **Marketplace Scam & Shipping Trap Shield** (`isMarketplaceScamOrShippingTrap()` blocking `shipping > $35.00`, `shipping > itemPrice * 0.20`, and unverified/1-qty sellers pricing `market > $200` items at `>35%` below market).
   - Every valid matched in-stock offer (even above buy trigger) is cached into `storeOffersCache.json` (`upsertStoreOfferCache()`) and `liveStock.json.__bestOffers` (`upsertBestCurrentOffer()`) with a plain-English shelf status tag (`⟦ UNDER TARGET (-$XX.XX) ⟧`, `⟦ CLOSE CALL (+$X.XX OVER TARGET — IN CUSHION) ⟧`, `⟦ NEAR MISS (+$XX.XX OVER TARGET) ⟧`, or `⟦ MUTED: OWNED ON WALL ⟧`).
   - Offers meeting or beating `effectiveCeiling` (always honoring `policyMaxBuy` on pre-orders, evaluating `isTierAMsrp` on raw shelf price `dropPrice <= msrpCeiling * 1.08` when shipping `<= $10`, and allowing the `+$5.00` ETB/Bundle / `+$10.00` Booster Box/Case **Close-Call Grace Cushion**) are written to `liveStock.json`, checked against Vault Mute / Wall Hunter Mode / per-store `alertState.json` deduplication (`${storeName}::${skuId}`), and returned as `action: 'BUY'`.
3. **Notification (`notifier.ts`):**
   - Rate-limited FIFO Discord webhook queue (`1250ms` spacing) sends tactical embeds with `1x / 2x / 3x` Shopify cart links, TCGPlayer/eBay comps, and `$/Pack` rip metrics, recording the alert in `dropsHistory.json`.

## 3. THE FAILURE GRAVEYARD (Never Repeat These Mistakes)

Every architectural flaw uncovered in our V4 -> V5 Ground-Truth Audit (plus any future `dropbot undo` reverts) is permanently entombed here:

- **`[FAILED - V4 Fake Big-Box Telemetry (`vampirePoller.ts:217, 313, 391, 438`)]`:** Using `Math.max(productMatches.length, 38)` and hardcoded `200 OK — 18 Checked` fallbacks in `catch` blocks made the dashboard report `200 OK` while `Pokémon Center` (Imperva `<title>Pardon Our Interruption</title>`), `Walmart` (PerimeterX `<title>Robot or human?</title>`), `Best Buy` (literal no-op stub with zero HTTP requests), and `Costco` (Next.js CSR shell with 0 `.product.html` links) actually extracted **`0` products**, and `Target` RedSky keyword search only returned 24 overpriced 3rd-party Target Plus scalpers (`BlueProton`, `Collectors Emporium`). **Rule:** Always log 100% honest parsed counts and real HTTP/challenge status.
- **`[FAILED - V4 Pre-Order Ceiling Override Trap (`evaluator.ts:706`)]`:** Forcing `effectiveCeiling = Math.min(policyMaxBuy, Math.round(rule.msrpCeiling * 1.05))` whenever a title contains `[PREORDER]` or `(Presell)`, which secretly slashed Scott's `$222` Delta Reign Booster Box trigger down to `$170` (`$58` on ETBs) and blocked `$205`–`$219` deals at `Trading Card Market` and `Stomping Grounds` while letting stores that wrote `WAVE 2` or `*Releases 11-06-2026*` pass! **Rule:** Always honor `policy.maxMarketBuyPrice` when Scott sets it above MSRP.
- **`[FAILED - V4 $6.99 Shipping Penalty Killing MSRP Unicorns (`evaluator.ts:735 & 892`)]`:** Checking `landedPrice <= msrp * 1.08` instead of `dropPrice <= msrp * 1.08`, causing a real `$54.99` MSRP ETB + `$6.99` shipping (`$61.98` landed at `JBs Emporium`) to fail the `$59.39` (`54.99 * 1.08`) MSRP Unicorn check, get suppressed by `muteVaulted`, and fail `$54.99–$61.00` triggers on limit-1/limit-2 (`stock: 1..2`) restocks. **Rule:** Evaluate `isTierAMsrp` on raw `dropPrice <= msrpCeiling * 1.08` (with nominal shipping `<= $9.99`) and never block sub-trigger item prices solely because `stock < qtyForFreeShip`.
- **`[FAILED - V4 Narrow Sub-Collection Lock-In (`storeHealth.json`)]`:** Auto-locking stores like `Zulus Games` onto `/collections/pokemon-booster-boxes-1` (blind to ETBs/Bundles), `Kanzen Games` onto `pokemon-tcg-mega-evolution`, `Card N All Gaming` onto `30th-pokemon-sealed`, `Sealed and Sleeved` onto `sealed-cases-pokemon`, `Poke-Collect` onto `blister-packs`, or `Safari Zone` onto generic `/products.json` (28 non-Pokémon items), blinding the bot to 90% of their Pokémon shelves.
- **`[FAILED - V4 "Booster Display" Regex Miss & $115/$275 Price Cap]`:** Requiring literal `box` instead of `(box|display)` on Booster Boxes (missing `Zulus Games` `Journey Together: Booster Display @ $209.99`), and dropping legitimate in-stock sealed boxes (`Destined Rivals Box @ $398`, `Obsidian Flames ETB @ $269`, `Paldea Evolved ETB @ $199`, `Evolving Skies Box @ $2,499`) via hardcoded `$115 / $275 / $1,600` ceilings in `getMaxPlausiblePriceCeiling()`.
- **`[FAILED - V4 61-Second Shopify Poll Cycle Latency (`lgsPoller.ts:688`)]`:** Polling all 91 stores in a single undifferentiated queue followed by a mandatory `15,000–22,000ms` dead sleep (`~61s` revisit cycle), plus firing 10 concurrent direct requests from the home IP (triggering Shopify Cloudflare `429`s that double latency on proxy retry). Fast `30–45s` MSRP restocks sell out between sweeps.
- **`[FAILED - V4 15-Minute TCGPlayer OOS Echo & Reddit Self-Post Leak]`:** Treating a single empty/timed-out TCGPlayer scrape as "Out of Stock" (causing repeat alerts every 15m) and polling general Reddit text discussions without requiring an outbound retailer URL.
- **`[FAILED - V4 Duplicate 9,780-Line `dashboard.html` Clone]`:** Maintaining two identical 9,780-line HTML files in root (`dashboard.html`) and `public/index.html`, with 3,800+ lines of Logan's Battle Stadium tangled inside the Sniper UI file.
- **`[FAILED - V4 Watchdog Single-Line `pm2 jlist` Regex (`scripts/watchdog.ps1`)]`:** Parsing multi-line `npx pm2 jlist` stdout with `^\[.*\]$` caused false-positive restarts every 5 minutes and spammed 15 boot digests to Discord.
- **`[FAILED - V4 TCGPlayer Shipping Scam & Unverified Bait-and-Switch Trap]`:** Assuming `freeShipping: true` on TCGPlayer listings allowed a scam listing (`Prismatic Evolutions ETB Case` at `$499.00 + $199.99 Shipping` by unverified 1-qty seller `Crawford gaming` vs. `$1,252` market) to pass as a deal.
- **`[FAILED - V4 Blind Pre-Release Calendar Warning Override]`:** Hardcoding `"Pre-release bleed — wait for launch"` whenever `daysUntilRelease >= 0` and `price > msrp` ignored actual rolling market floor data—falsely warning Scott to wait on a `$79.99` (`$86.98` landed) *Delta Reign* ETB even though it beat his `$93` slider and undercut the `$100.00` live market comp floor by `$13–$20`. All buy/wait guidance must be driven by real 14d/30d/60d/90d price history and live market floor spread.
- **`[FAILED - Broad Feed Single-Card & Slab Leak]`:** Widening Shopify collection feeds to `/collections/pokemon/products.json` and polling `?limit=50` exposed high-value single cards, slabs, and loose packs whose titles contained set names. All pollers and `matchProductToSku()` must enforce a strict Sealed-Only positive form-factor gate and a Single-Card/Slab/Loose-Pack blacklist.
- **`[FAILED - Hardcoded $115 ETB Market Value Placeholder]`:** Legacy catalog seeding stamped `estimatedMarketValue: 115` (`defaultMarketBaseline: 115`) onto standard Scarlet & Violet era ETBs (*Paradox Rift*, *Scarlet & Violet Base* Koraidon/Miraidon, *Temporal Forces*, *Paldean Fates*, and *Mega Discovery*), distorting discount math and slider recommendations. All standard in-print/recent S&V ETBs must use accurate `$46–$58` market baselines and dynamically derive `estimatedMarketValue` from the median of the lowest 3–5 verified in-stock LGS offers in `storeOffersCache.json` / `salesHistory.json` whenever 2+ real store offers exist.

- **`[FAILED - V5 `Math.sin` Synthetic 90-Day History & Silent Slider Override (`trendAdvisor.ts:134–156, 222` & `server.js:2263–2361`)]`:** Backfilling missing historical days with `Math.sin(seed * 0.45 + d * 0.14)` sine waves and `ebayFloorPrice = tcgFloorPrice * 0.99` fabricated fake `60D Elastic Dip` / `Bleeding Down` signals, while `effectiveTargetCeiling = Math.max(policyMaxBuy, autoPilotCeiling)` silently raised buy ceilings up to +10% above Scott's manually configured slider. **Rule:** Compute rolling metrics strictly over real recorded timestamps (exposing honest sample counts when `< 14d`) and NEVER let Auto-Pilot automatically raise `effectiveTargetCeiling` above `Math.max(msrpCeiling, policyMaxBuy)`.
- **`[FAILED - V5 Synchronous Pre-Alert Comp Scrape Blocking (`notifier.ts:333`, `fastTier1Poller.ts:237`, `lgsPoller.ts:637`)]`:** Calling `await getDualMarketComps()` synchronously inside `sendAlert()` (and awaiting `processIncomingDrop()` sequentially inside Shopify variant loops) added `1.5s–15.0s` of live TCGPlayer + eBay scraping latency BEFORE firing the Discord alert and stalled subsequent variants in multi-SKU restocks. **Rule:** Always Fire-Then-Enrich — dispatch the alert in `0ms` using cached/baseline comps (`?payment=shop_pay` + native mobile ATC links), then enrich live comps asynchronously and `PATCH` the message in the background.
- **`[FAILED - V5 `axios` Fake WAF Browser Bridge (`wafBrowserBridge.ts`)]`:** Defining `CHROME_LAUNCH_FLAGS` (`--disable-blink-features=AutomationControlled`) inside a module that still executed plain Node `axios.get()` with Node TLS JA3/JA4 fingerprints and zero JS execution—failing 100% of Imperva (`Pokemon Center`), PerimeterX (`Walmart`), and Akamai (`GameStop`) challenges. **Rule:** Never masquerade plain `axios` requests as a headless browser bridge.
- **`[FAILED - V5 `\bpack\b` / `\bpromo\b` / `\bfoil\b` / `\bsingle\b` Sealed Collateral Damage (`policies.ts:156–200, 250–288`)]`:** Applying `/\bpack\b(?!\s*box)/i`, `/\bpromo\b/i`, `/\bfoil\b/i`, `/full\s*art/i`, `/\bholo\b/i`, and `/\bsingle(s)?\b/i` unconditionally even when a positive sealed container keyword (`Booster Bundle`, `Elite Trainer Box`, `Booster Box`, `UPC`) was present—silently rejecting `"6-Pack Booster Bundle"`, `"ETB (Includes Full-Art Foil Promo Card)"`, `"Battle Styles Single Strike ETB"`, and `"Booster Box - Single Box"` variants, while also truncating Tier-1 Shopify collections at `?limit=50` and failing to convert Canadian `CAD` storefronts (`~0.72` USD). **Rule:** Context-sensitive card/pack words must yield when a valid sealed container keyword is present (unless paired with `empty` / `box only` / `promo only` / `acrylic` / grading terms).
- **`[FAILED - V5 2-Process `storeOffersCacheMem` Split-Brain Overwrite (`evaluator.ts` & `server.js:2790, 2802`)]`:** Holding separate in-memory `storeOffersCacheMem` copies in `pokemon-drop-bot` and `drop-bot-dashboard` caused UI slider or `[WALL/DAD/LOGAN]` saves in `server.js` to call `refreshCachedStoreOffersStatus()` and overwrite `storeOffersCache.json` on disk with stale boot-time memory, wiping hours of fresh poller discoveries, while re-reading/re-parsing `~1 MB` of JSON synchronously on every `/api/status` & `/api/engine-room` poll (`965ms` latency) and letting `singlesCache.json` `compBenchmarks` grow unbounded (`2,801` keys). **Rule:** Always sync `storeOffersCache.json` by `mtimeMs` before mutating, memoize dashboard API responses by file `mtimeMs`, and enforce strict 500-key LRU bounds on `singlesCache.json`.
- **`[FAILED - V5/V6 Zeno's Paradox `dropPrice * 0.92` Self-Undercutting & Rip-Hunt `$64.89` Slider Clamp (`evaluator.ts:1497` & `src/engine/trendAdvisor.ts:220–240`)]`:** Passing the incoming offer's own `dropPrice` as `lowestShelfPrice` into `computeAutoPilotTarget()` set `autoPilotCeiling = Math.round(dropPrice * 0.92)` on every `isBleedingDown` SKU—making `x <= 0.92x` mathematically impossible (`0%` pass rate) and silencing real sub-slider deals like unowned *Destined Rivals ETB* at `$109.99` (`$111` slider). Simultaneously, clamping `ripHuntCeiling` to `msrpCeiling * 1.18` (`$64.89`) when `wallOwned === true` (`1/3` or `2/3`) silently crushed Scott's `$121` *Prismatic Evolutions* (`2/3`) and `$93` *Delta Reign* (`1/3`) sliders. **Rule:** Always honor Scott's `policyMaxBuy` slider directly (`effectiveTargetCeiling = userManualCeiling`); keep `BLEEDING DOWN` strictly as an advisory `trendVerdictLabel` and Capital Advisor caution signal computed from historical market floors—never from `dropPrice`.
- **`[FAILED - Pre-Send `alertState.json` Lock on Transient DNS Failure & Immortal Reddit Ghosts (`evaluator.ts:1923–1932` & `notifier.ts`)]`:** Writing the 12h–24h deduplication lock to `alertState.json` inside `evaluateItem()` *before* Discord HTTP `2xx` confirmation caused transient DNS errors (`getaddrinfo ENOTFOUND discord.com`) to drop alerts permanently, while `reddit_t3_*` tips had no TTL and polluted `#1/#2` shelf slots for days. **Rule:** Enforce Commit-After-Send (`commitAlertDelivery` only after Discord/Telegram confirms delivery, with `1500ms`/`4000ms` network/DNS retries) and enforce a strict `4h` TTL on all `reddit_*` / `PKMNTCGDeals` entries.
- **`[FAILED - `axios` HTTP/1.1 Bot-Score `429` Tarpit, Dual-Poller Contention & `588 MB` `[SEEN]` Stdout CPU Burn (`lgsPoller.ts`, `fastTier1Poller.ts`, `listener.ts:87`)]`:** Fetching Shopify `/products.json` via `axios.get()` (Node `https` HTTP/1.1 without HTTP/2 ALPN, sending `Accept: application/json` without `Sec-Fetch-*` navigation headers, plus 78 un-throttled `/cart.js` FX probes and double-polling all 25 `TIER1_FAST` stores across both pollers) triggered Cloudflare Bot Fight (`Bot Score = 1`), shunting requests into Shopify's `1 req/min` `TOO_MANY_REQUESTS` (`retry-after: 60`) tarpit (`25/90` stores degraded), while logging `[SEEN]` on every rejected Near-Miss bloated `pokemon-drop-bot-out-0.log` to `588.0 MB` at `73.5%` CPU. **Rule:** Always fetch Shopify JSON feeds via Node 26 native `fetch()` (Undici TLS 1.3 + HTTP/2 ALPN) with full Chrome document navigation headers (`BROWSER_NAV_HEADERS`), `ETag`/`If-None-Match` `304` short-circuiting, Tier-1 reconciliation only every 5th `lgsPoller` cycle, per-store (never global-lane) proxy fallback, and zero `console.log` calls inside per-variant hot loops.

- **`[FAILED - V6 Pass 1 False-Green `0`-Node Big-Box Parsers (`GameStop` `[object Object]`, `Amazon` `4,500B` Cap, `Costco` Empty CSR Shell, `Best Buy` HTTP/1.1 Akamai Tarpit, & Datacenter Proxy Imperva/PX Auto-Block)]`:** (1) `String(obj.availability)` on GameStop's nested `{ readyToOrder: true, available: true }` object evaluated to `"[object Object]"`, missing `20–35` live tiles; (2) slicing Amazon cards at `4,500` bytes with `(?=data-asin=)` cut off prices sitting at byte `7,043+` and grabbed brand `<h2>Pokémon</h2>`; (3) marking `HTTP 200` pages as `200 OK // 0 IN STOCK` when `totalNodesFound === 0` masked Costco's unhydrated Next.js shell as healthy; (4) `axios` HTTP/1.1 hit Akamai's TCP tarpit (`ERR_CANCELED`) on Best Buy, and falling back to Webshare datacenter ASNs (`146.103.1.23`) guaranteed Imperva `B10` / PerimeterX `412` blocks while `page.route('**/*')` leaked CDP interception timing. **Rule:** Every Big-Box adapter must return `{ totalNodesFound, inStockOffers }`, `0`-node `200` pages must flag `PARSER_BLIND_0_NODES` (never green `200 OK`), Playwright must use System Chrome (`channel: 'chrome'`, `--headless=new`, `ignoreHTTPSErrors: true`) with passive `page.on('response')` wire-tapping (zero `page.evaluate` fetch injection, zero `page.route` interception), and Imperva/PerimeterX targets must never fall back to datacenter proxies.

- **`[FAILED - V6 Pass 2 Continuous Home-IP WAF Hammering, Keep-Alive Proxy Reddit `429` Pinning, Plush-Bundle Leaks, & GameStop `MSRP * 1.08` Pre-Slider Drop]`:** Re-hitting Imperva (`Pokémon Center`), PerimeterX (`Target`, `Walmart`, `Sam's Club`), and Kasada (`Costco`) from the home IP every `75s–180s` burned residential IP reputation for zero nodes; `HttpsProxyAgent({ keepAlive: true })` pinned a single rate-limited Webshare exit IP across Reddit `429` retries; plush/Squishmallow bundles lacked an unconditional `GLOBAL_JUNK_EXCLUSIONS` rule; and `GameStop` `allowAboveMsrpSliderFallthrough: false` dropped in-stock 1P ETBs (`$84.99–$99.99`) before `evaluator.ts` could compare them against Scott's manual sliders (`$93` Delta Reign). **Rule:** Enforce the 2-strike `6h` `WIRE_ARMED_IP_SHIELD` cooldown backed by Bluesky Jetstream WS + per-request rotating Webshare Proxy-Reddit (`keepAlive: false`), block `/\bsquishmallows?\b|\bplush(?:ie|ies)?\b/i` unconditionally, and pass GameStop 1P offers through to `evaluator.ts` slider checks.
- **`[FAILED - Unbounded `node -e` Probes Importing Daemon Modules Without `.unref()`, `AbortSignal.timeout(5000)`, or `finally { process.exit(0); }`]`:** Importing `lgsPoller` (`HttpsProxyAgent({ keepAlive: true })`), `policies` (`fs.watchFile`), or `publicRestockWire` (Jetstream WebSocket, intervals, or unshorten fetches without `AbortSignal.timeout(5000)`) inside ad-hoc `node -e` probes held libuv handles open and hung the event loop. **Rule:** Never import full daemon startup modules without `.unref()` on timers; always enforce `AbortSignal.timeout(5000)` on every `fetch`/unshorten hop, `.close()` test WebSockets immediately on `open`, and wrap every verification script with `setTimeout(() => { console.error('PROBE_TIMEOUT'); process.exit(1); }, 20000).unref()` + `finally { process.exit(0); }`.
